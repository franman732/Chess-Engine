# Chess Engine
A chess engine being developed from scratch to explore search algorithms, evaluation systems, and performance optimization techniques.

## Current Features
- Move generation
- Legal move validation
- Board state management
- Evaluation function
- Minmax search
- Alpha-beta pruning
- Move ordering: captures, promotions, killer moves, 

## In Progress
- Transposition tables

## Planned Features
- Bitboard representation
- C++ rewrite for performance optimization
- GUI/web frontend
